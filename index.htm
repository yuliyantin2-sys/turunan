Turunan (diferensial) mengukur seberapa cepat suatu nilai berubah. Kecepatan sesaat pada kendaraan, laju pertumbuhan populasi bakteri, hingga optimasi keuntungan bisnis—semuanya menggunakan konsep turunan.

Tujuan Pembelajaran 3

Menentukan Turunan dengan Konsep Limit (h → 0)

Geser nilai h mendekati 0 untuk melihat tali busur (secant) berubah menjadi garis singgung (tangent) kurva.

Definisi Limit Turunan
f'(x) = limh→0 [ f(x + h) − f(x) ] / h
Kurva: f(x) = x2

Kontrol Pergeseran Nilai h

Titik Awal x: 1.00
Titik Geser x + h: 2.00
Kemiringan Tali Busur (Secant): 3.00
Turunan Sejati (h → 0): 2.00

Contoh Soal Penerapan Konsep Limit untuk Turunan

Contoh 1: Fungsi Aljabar f(x) = 3x − 1

Tentukan turunan dari f(x) = 3x − 1 menggunakan definisi limit f'(x) = limh→0 [ f(x+h) − f(x) ] / h.

Penyelesaian Langkah demi Langkah:
1. f(x + h) = 3(x + h) − 1 = 3x + 3h − 1
2. f(x + h) − f(x) = (3x + 3h − 1) − (3x − 1) = 3h
3. f'(x) = limh→0 [ 3h / h ]
4. f'(x) = limh→0 3 = 3
Contoh 2: Fungsi Trigonometri f(x) = sin(x)

Tentukan turunan dari f(x) = sin(x) menggunakan definisi limit.

Penyelesaian Langkah demi Langkah:
1. f'(x) = limh→0 [ sin(x + h) − sin(x) ] / h
2. Gunakan rumus jumlah sinus: sin(x+h) = sin x cos h + cos x sin h
3. Bentuk limit: limh→0 [ sin x(cos h − 1) + cos x sin h ] / h
4. Karena lim(cos h - 1)/h = 0 dan lim(sin h)/h = 1, didapat f'(x) = cos(x)

Rumus Turunan Fungsi Aljabar, Trigonometri, Perkalian, Pembagian, & Derajat Tinggi

Eksplorasi rumus baku turunan lengkap termasuk turunan tingkat tinggi (kedua, ketiga, hingga ke-n) untuk analisis laju perubahan lanjutan.

Aturan Pangkat Dasar
f(x) = a · xn
f'(x) = a · n · xn−1
Aturan Jumlah & Selisih
f(x) = u(x) ± v(x)
f'(x) = u'(x) ± v'(x)

Latihan Cepat Aljabar

Tentukan turunan dari fungsi: f(x) = 4x3 − 5x2 + 7

Turunan Sinus
f(x) = sin(x)
f'(x) = cos(x)
Turunan Kosinus
f(x) = cos(x)
f'(x) = −sin(x)
Turunan Tangen
f(x) = tan(x)
f'(x) = sec2(x)
Turunan Cotangen
f(x) = cot(x)
f'(x) = −csc2(x)
Turunan Secan
f(x) = sec(x)
f'(x) = sec(x) · tan(x)
Turunan Cosecan
f(x) = csc(x)
f'(x) = −csc(x) · cot(x)

Latihan Cepat Trigonometri

Tentukan turunan dari fungsi: f(x) = 3 sin(x) + 2 cot(x)

Aturan Perkalian Dua Fungsi
f(x) = u(x) · v(x)
f'(x) = u'(x) · v(x) + u(x) · v'(x)

Mantra mudah diinget: "Turunan pertama kali fungsi kedua, ditambah fungsi pertama kali turunan kedua."

Latihan Aturan Perkalian

Aturan Pembagian Dua Fungsi
f(x) = u(x) / v(x)
f'(x) = [ u'(x) · v(x) − u(x) · v'(x) ] / [ v(x) ]2

Mantra mudah diinget: "U ' aksen V dikurang U V ' aksen, dibagi V kuadrat."

Konsep Aturan Rantai (Chain Rule)

Bagaimana Menurunkan Fungsi Komposit / Berpangkat?

Aturan Rantai digunakan saat kita ingin mencari turunan dari fungsi komposit (fungsi di dalam fungsi), seperti f(x) = [g(x)]n atau fungsi trigonometri dengan sudut majemuk seperti sin(ax + b).

Rumus Umum Aturan Rantai:
f(x) = [ g(x) ]n → f'(x) = n · [ g(x) ]n−1 · g'(x)
Atau dalam bentuk notasi Leibniz: dy/dx = (dy/du) · (du/dx)
Contoh Penerapan: Tentukan turunan dari f(x) = (3x2 − 5)4
1. Turunkan pangkat luar: 4 · (3x2 − 5)3
2. Kalikan dengan turunan fungsi di dalam kurung: g'(x) = 6x
3. Hasil Akhir: f'(x) = 4 · (3x2 − 5)3 · (6x) = 24x(3x2 − 5)3

Latihan Cepat Aturan Rantai

Tentukan turunan dari fungsi trigonometri: f(x) = sin(4x − 2)

Konsep Turunan Tingkat Tinggi

Apa itu Turunan Derajat Tinggi?

Jika turunan pertama f'(x) memberikan laju perubahan fungsi, maka menurunkan f'(x) sekali lagi menghasilkan Turunan Kedua (f''(x)) yang mengukur laju dari laju perubahan (kecepatan perubahan kemiringan / kecekungan kurva atau percepatan dalam fisika). Proses ini dapat dilanjutkan ke turunan ketiga (f'''(x)) hingga turunan ke-n (f(n)(x)).

Turunan Pertama
f'(x) atau dy/dx
Kecepatan / Kemiringan
Turunan Kedua
f''(x) atau d2y/dx2
Percepatan / Kecekungan
Turunan ke-n
f(n)(x) atau dny/dxn

Penyelesaian Masalah Kontekstual & Limit Terkait

Bagaimana konsep turunan dan aturan L'Hôpital menyelesaikan masalah optimasi nyata serta limit fungsi aljabar & trigonometri.

Optimasi Kontekstual (Industri)

Pembuatan Kotak Tanpa Tutup

Sebuah karton berukuran 12 cm × 12 cm akan dibuat kotak tanpa tutup dengan memotong keempat sudutnya seluas x. Tentukan nilai x agar volume maksimum!

Strategi Pemecahan:
1. Fungsi Volume: V(x) = x(12 − 2x)(12 − 2x) = 4x3 − 48x2 + 144x
2. Titik stasioner: V'(x) = 12x2 − 96x + 144 = 0
3. Akar persamaan: x = 2 (karena x = 6 tidak memenuhi).
Teruji Kontekstual Nyata
Kecepatan & Percepatan Gerak

Posisi Partikel terhadap Waktu

Posisi partikel dinyatakan oleh s(t) = t3 − 6t2 + 9t. Kapan partikel berhenti (v = 0)?

Strategi Pemecahan:
1. Kecepatan: v(t) = s'(t) = 3t2 − 12t + 9
2. Saat berhenti, v(t) = 0 → 3(t − 1)(t − 3) = 0
3. Didapat waktu: t = 1 detik atau t = 3 detik.

Turunkan penyebut: 1
Substitusi x = 2 → 2(2) / 1 = 4
